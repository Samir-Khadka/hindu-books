# Hindu Books 📚

A free, bilingual (English/नेपाली) library of Hindu scriptures.

## What's inside

- **Bhagavad Gita** — all 18 chapters, summaries, and key verses in Sanskrit + English + Nepali
- **Ramayana, Mahabharata, Upanishads** — coming soon

## Features

- 🌐 Bilingual EN/NE toggle on every page
- 🔍 Full-text search across chapters and verses
- 📖 Clean reading interface with Devanagari Sanskrit
- 🎨 Light premium design (warm ivory + violet + gold)

## Run locally

```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

## Deploy

Free on Render (see `render.yaml`) or any Python host.
